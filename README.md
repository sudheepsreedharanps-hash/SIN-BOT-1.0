# VEX Guild Bot

A Discord.js v14 bot for VEX Guild.

## Setup

1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run:
   `npm install`
4. Rename `.env.example` to `.env`.
5. Put your Discord bot token, Application ID, and VEX Guild server ID in `.env`.
6. Add the channel/role IDs you want to use.
7. Run:
   `npm start`

## Commands

- `/help`
- `/ping`
- `/serverinfo`
- `/userinfo`
- `/warn`
- `/kick`
- `/ban`
- `/timeout`
- `/giveaway`
- `/ticket`
- `/close`

## Important

Never upload `.env` or your bot token to GitHub or send the token to anyone.
